# Glucose ablation and transportability in prevalent diabetes classification

**Status: documentation-only research portfolio entry; NOT an executable reproduction.**

## Study overview
De-identified Bangladesh outpatient data, n=1,065. The manuscript compares glucose-only logistic regression with random forests including/excluding glucose; post-hoc ROC-AUC 0.9268, 0.9505 and 0.9239 respectively. This is prevalent-status classification, not prospective risk prediction.
